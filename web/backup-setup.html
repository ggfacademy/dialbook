Connect Dropbox for daily backups

Do this once. It gives GitHub permission to put the nightly backup in your Dropbox.

1. Create a Dropbox app

  1. Open dropbox.com/developers/apps/create and sign in with the Dropbox account that syncs to F:\Dropbox.
  2. Choose Scoped access → Full Dropbox. Name it e.g. GGF CRM Backup → Create app.
  3. Open the Permissions tab, tick files.metadata.read, files.content.write and files.content.read, then press Submit at the bottom.
